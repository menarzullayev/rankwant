# Xavfsizlik siyosati

RankWant — foydalanuvchi kodini yurgizadigan platforma, shuning uchun zaiflik xabarlarini jiddiy qabul qilamiz.

## Zaiflik haqida qanday xabar berish kerak

**Ommaviy issue ochmang.** Xabarni GitHub'ning yopiq kanali orqali yuboring:
[Security → Report a vulnerability](https://github.com/menarzullayev/rankwant/security/advisories/new).
Xabar faqat repo egasiga ko'rinadi.

Xabarga quyidagilarni yozing: nima buzilgan, qanday takrorlanadi, qaysi sahifa yoki endpoint, qanday ta'sir qiladi.

## Nimalar eng muhim

- Judge sandbox'idan chiqib ketish (foydalanuvchi kodi host yoki boshqa foydalanuvchiga tegishi).
- Boshqa foydalanuvchining hisobiga, ma'lumotiga yoki Qvant balansiga kirish.
- Verdikt yoki reytingni soxtalashtirish.
- Ma'lumotlar bazasi, sirlar yoki zaxira nusxalarining oshkor bo'lishi.

## Nimalar qamrovdan tashqari

Avtomatik skanerning tasdiqlanmagan hisoboti, DoS sinovlari, ijtimoiy muhandislik va bizga tegishli bo'lmagan uchinchi tomon xizmatlari.

## Javob muddati

Platforma hozir ishlab chiqilmoqda (alpha). Xabarga imkon qadar tez javob beramiz; tuzatish chiqqach, xohlasangiz, hisobot muallifini tan olamiz.
