### 💡 Nega aynan bu 9 talik

1. **Hammasi 1–3 bo'g'in** — telefon ekranida, jadvalda, ism yonida sig'adi.
2. **Hammasi inglizcha, lekin o'zbekcha chiroyli o'tadi** — `Spark` → *Uchqun*,
   `Nova` → *Nova*, `Comet` → *Kometa*.
3. **Har biri ko'p ma'noli** — `Nova` lotinchada "yangi", `Zenith` "cho'qqi",
   `Corona` "toj" — o'z ma'nosidan tashqari, ramziy qatlam ham bor.
4. **Logotip bilan mos** — ikki cho'qqi + yulduz. `Star`, `Nova`, `Supernova`
   bevosita shu belgiga ishora qiladi.
5. **Rang bilan mos** — `--rw-rank-1…9` tokenlarida tabiiy o'qiladi
   (kulrang → yashil → ko'k → binafsha → qizil → pushti).

## ⚠️ Uch muhim eslatma

1. **Bahsli ma'lumotlar.** `Phoenix A*` massasi manbalarda **1×10¹⁰ dan
   1×10¹¹ M☉** gacha farq qiladi — bir maqola hatto o'ziga zid keltirgan.
   `Ton 618` rasmiy Vikipediya ma'lumoti **40.7–66 mlrd M☉** (2019 dagi
   qayta o'lchov 40.7 ga tushirgan). Ishonchli raqamlar ishlatildi.

2. **Hercules–Corona Borealis Great Wall** mavjudligi **bahsli** — 2014 da
   topilgan, lekin ba'zi astronomlar uni "tuzilma" deb tan olmaydi. Ro'yxatga
   kiritildi, lekin bu cheklov yozildi.

3. **Kichik obyektlar chizig'i.** `Meteoroid` ning massasi **1 grammdan
   1000 tonnagacha** — bu chegaraviy aniqlik, aniq raqam emas.

## Keyingi qadam

Nom tanlangach:

```bash
cd rankwant
# 1. Kod nomlarini yangilash (agar kerak bo'lsa)
#    apps/api/profiles/titles.py → TITLES
# 2. 10 tilning tarjimalarini yangilash
#    apps/web/src/i18n/locales/*.ts → title.<kod>
# 3. Validatorlar (majburiy)
python tools/check_i18n.py
python tools/check_locales_parity.py
python tools/check_contrast.py
python tools/check_hardcoded.py
# 4. Agar kod ham almashsa — nom mavjudligi
cd tools/naming && python check_names.py candidates.txt
```
