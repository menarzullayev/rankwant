# Rejalashtirilgan yo'nalishlar (RankWant platforma sifatida)

**Sana:** 2026-11-15. **Manba:** Saidakbar aka, bosh sahifa heroi muhokamasi.
**Holat:** reja. Hech biri qurilmagan. Sayt ularni **ko'rsatmaydi** (hero qarori:
faqat tayyor yo'nalish ko'rinadi, `docs/decisions/2026-11-15-guest-hero.md`).

## Tartib

Avval **CP bo'limi** (sport dasturlash va olimpiada) tugatiladi. Quyidagilar
undan keyin; ularning hozir ustuvorligi yo'q (egasi: «hozir muhim emas»).

## Tuzilma qarori

RankWant — platforma. Har yo'nalish alohida **subdomen** (`science.rankwant.uz`,
`games.rankwant.uz`, …), umumiy hisob va Qvant bilan. `rankwant.uz` — kirish eshigi va
hozirgi flagman (CP).

## Cheklovlar
